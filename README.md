# 🚀 Premium Media Downloader (Bot + Web)

A dual-engine platform to download videos from Instagram, Facebook, Twitter, and Snapchat. 
This repository runs both a Telegram Bot and a Web Interface simultaneously on a single server.

## Features
- 🌐 Modern UI Web Downloader (Tailwind CSS)
- 🤖 24/7 Telegram Bot
- ⚡ Fast direct-link extraction
